# 🧠 TermDefiner - 名詞定義記憶 App
TermDefiner 是一個輕量、直覺且無依賴任何外部框架的純前端 Web 應用程式。專為幫助學習者記憶與測驗大量的專業名詞定義（如：科技、商業、資料分析等領域）而設計。

透過智慧化的「刪去法」與「自動跳題」機制，讓 100 題的長篇測驗變得順暢且不費力。

### 🔗 [👉 點此體驗] https://kailin80.github.io/final2nd/

---

## ✨ 核心功能 (Features)

*   **🎲 隨機題庫系統**：每次重新開始測驗時，100 道題目會自動打亂順序，確保真正考驗記憶力而非背誦順序。
*   **🔍 智慧搜尋下拉選單**：作答時支援關鍵字即時搜尋，快速從上百個名詞中找到目標。
*   **🚫 刪去法機制**：已選擇過的名詞會自動從下拉清單中隱藏，縮小作答範圍，降低後期作答難度。
*   **⚡ 順暢的作答體驗 (UX)**：作答完畢後，系統會自動跳轉至「下一題未作答」的題目，無需手動切換。
*   **📊 即時進度追蹤**：左側側邊欄即時顯示 100 題的作答狀態、已選答案，並支援點擊快速跳題。
*   **✅ 嚴謹的交卷機制**：必須完成所有題目（100/100）才能點擊交卷，避免誤觸。
*   **📝 完整的錯題檢討**：測驗結束後不僅顯示總分，還會完整列出「答錯的題目」、「你的錯誤答案」以及「正確解答」，方便針對性複習。
*   **📱 響應式設計 (RWD)**：完美支援桌機與手機，在行動裝置上側邊欄會自動轉換為頂部滑動佈局。

## 🛠 技術棧 (Tech Stack)

本作案採用純前端技術開發，**零外部依賴 (Zero Dependencies)**：
*   **HTML5**：語意化標籤與介面結構。
*   **CSS3**：CSS Variables (主題色配置)、Flexbox 排版、Media Queries (響應式設計)、自定義滾動條與動畫過渡。
*   **Vanilla JavaScript (ES6+)**：DOM 操作、陣列處理 (Map, Filter, Sort)、事件監聽與狀態管理。
